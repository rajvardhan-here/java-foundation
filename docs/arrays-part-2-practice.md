# Arrays Part 2: Practice Set

Solve these in order. Start with a straightforward solution, then improve it when possible.

## Beginner

1. Print every non-empty subarray of an integer array.
2. Calculate the sum of every subarray.
3. Find the maximum and minimum subarray sums using brute force.
4. Build a prefix-sum array and answer multiple inclusive range queries.

## Intermediate

5. Find the maximum subarray sum using Kadane's algorithm.
6. Return the start and end indices of the maximum-sum subarray.
7. Count subarrays whose sum equals a target value.
8. Find an equilibrium index where the left-side sum equals the right-side sum.

## Edge cases

- A single-element array.
- An array containing only negative values.
- An array containing zeros.
- A range that starts at index zero.
- A query covering the entire array.
- Null and empty inputs, following each method's documented validation behavior.

## Complexity checkpoint

For each solution, record its time complexity, auxiliary space, whether it modifies the input, and the edge cases you tested.
