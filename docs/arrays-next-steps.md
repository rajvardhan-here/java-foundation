# Arrays: Next Practice Steps

## Two pointers
- [ ] Find a pair with a target sum in a sorted array.
- [ ] Reverse an array without allocating another array.
- [ ] Move zeroes while preserving non-zero order.
- [ ] Remove duplicates from a sorted array.
- [ ] Solve Three Sum and explain duplicate skipping.

## Sliding window
- [ ] Find the maximum sum of a window of size k.
- [ ] Find the maximum average of a window of size k.
- [ ] Find the minimum length subarray whose sum reaches a target (positive values).
- [ ] Find the longest substring without repeated characters.

## Sorting and matrices
- [ ] Implement bubble, selection, and insertion sort.
- [ ] Explain why merge sort needs extra memory.
- [ ] Trace one quicksort partition by hand.
- [ ] Transpose a rectangular matrix.
- [ ] Traverse a matrix in spiral order.

For every solution, test empty input where supported, a single element, duplicates, negative values where applicable, and already sorted input.
